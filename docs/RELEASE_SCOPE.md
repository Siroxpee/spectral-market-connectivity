# Public release scope

This is an explicit source/results export, not a copy of the working archive. It includes active Python science/acquisition modules, offline synthetic checks, frozen protocols, an aggregate model comparison and ten derivative ETF figures. No provider raw observations, per-asset returns, raw workbook/API archives, local catalog, deployment identities, credentials, résumé/career material, private URLs, assistant instructions or conversation logs are included.

Native frozen sources and private originals remain unchanged. The release preserves source Python bytes and protocol hashes. It omits a workstation-font-specific PDF renderer, a one-time metadata repair and private dashboard/presentation packaging. Full archive workflows require data unavailable in this compact repository; the default quickstart works independently. Findings remain exploratory and no dependable forecasting, trading or arbitrage advantage is asserted.

`RELEASE_MANIFEST.json` records each public file's SHA-256 and the exact source-copy status. `release_validation.json` records the environment, offline commands and portable-path checks. Those receipts contain no machine-specific paths or raw provider data.
